# Bank System – SQE Exercise

Business logic module of a simple bank system with a command-line frontend, developed as the exercise for the course Software Quality Engineering. The focus is on applying the course's quality engineering methods in each phase: requirements engineering, architecture, design, test design, implementation and traceability.

Team: Samuel Erdö, Servet-can Simsek
